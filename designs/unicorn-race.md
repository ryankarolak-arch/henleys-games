# Unicorn Race

**Designer:** Henley
**Status:** Design locked — ready to build after Shell + Tic Tac Toe + Pong + Word Scramble ship.

## Setting
Candy land — lollipop trees, cotton-candy clouds, gumdrop hills.

## Mode
Single player vs. computer opponents.

## Character Select
Player picks a unicorn before the race.

- **Sparkle** — purple body, pink mane, sparkle trail *(Henley's pick)*
- 2–3 alternate unicorns with different color combos (TBD during build)

## Movement
Side-scrolling runner. Unicorn runs on the ground.
**Tap anywhere** (or press **Space**) = jump. Jumping briefly "flies" with a sparkle trail — this covers Henley's "both running and flying" answer.

## Collectibles
**Gems** scattered along the track. Each gem = bonus points added to finish score.

## Obstacles
**Grumpy trolls** — jump over them. Hitting one slows you down briefly.

## Win Condition
First to cross the finish line wins the race. Gem score is added on top as a bonus.

## Victory Screen
Big "YOU WON!" banner + confetti + sparkle trail celebration.

## Controls
- **iPad / touch:** tap anywhere to jump
- **Keyboard:** Space or Up arrow to jump

One-button design keeps it age-5 friendly.

## Assets needed (for build phase)
- Unicorn sprite (idle + run + jump poses) × number of characters
- Gem sprite (1 type for v1; could add rarer gems later)
- Grumpy troll sprite
- Candy-land parallax background layers (clouds, hills, ground)
- Finish-line banner
- Sound effects: jump, collect gem, hit troll, victory
